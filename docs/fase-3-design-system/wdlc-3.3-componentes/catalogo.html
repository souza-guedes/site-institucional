Não envie documentos nem dados sensíveis por aqui. O primeiro contato não constitui consulta jurídica nem estabelece relação advogado-cliente.

.notice.of

  2. Leitura pelos sóciosA mensagem é lida diretamente por um dos sócios, que retorna pelo canal que você informar.
  3. Reunião com agendamentoQuando for o caso, a conversa continua em reunião na sede.
.steps

Fazer

  • Apresentar os canais como informação ("Fale com o escritório pelos canais oficiais").
  • Repetir que o primeiro contato não é consulta jurídica.
  • Botão "Copiar" com retorno acessível (texto em região aria-live).

Não fazer

  • Urgência ou escassez ("Vagas limitadas", "Fale agora mesmo").
  • Link direto para WhatsApp com mensagem pronta de captação.
  • Pop-up, chat automático ou janela que se abre sozinha.
